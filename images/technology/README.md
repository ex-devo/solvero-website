# Technology logo sources

The homepage identifies technologies used to deliver solutions. The static grid preserves all sixteen technologies from the previous marquee, with one readable name per mark. The original coloured PNG/WebP assets remain unchanged in images/Logos and images/optimised.

## Source and artwork treatment

Fourteen single-colour marks come from Simple Icons, pinned to commit c71c69e3a27e4436936b831c72643e6513b9f49b. AWS and Azure use Devicon plain vector artwork, pinned to commit 6a37858047b0e8d9c9c0e68f4a071fc410652e89. These are maintained icon collections; they are not all official vendor downloads. Each source file is retained unmodified in source/. Collection licences are retained there. Brand names and marks remain their owners' trademarks. Angular artwork is attributed to Angular under CC BY 4.0, as identified by the source collection.

The display copies use near-black (#040506), trimmed transparent bounds and individual display dimensions. The shapes retain their proportions. Image dimensions start with measured visible ink coverage, then are adjusted by eye; equal file dimensions alone do not establish optical equality. Labels remain visible without hover; empty image alt text avoids reading the same technology name twice.

Brand and source references for every mark are recorded in manifest.json. The sourced mono versions replace mixed padded raster wordmarks. No new dependencies or external image requests are required.
