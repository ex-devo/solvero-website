# Approved homepage photographs

Four non-personal photographic images generated with built-in imagegen and approved for publication on 20 October 2026. They cover About Solvero, Financial Services Expertise, Integrate Disparate Systems and Process Improvement.

PNG masters are retained in `source/`; full generation prompts are in [source/prompt-set.json](source/prompt-set.json). The [manifest](manifest.json) records alt text, dimensions and responsive WebP variants. `npm run images` regenerates the variants at quality 84, effort 6, without enlargement.

About uses 600/900/1200px variants. Expertise cards use 480/768/960/1200px variants. All images have descriptive alt text, intrinsic dimensions, responsive sizing and lazy loading.

Previous homepage illustrations, their source masters, all original stock images and the shared background remain preserved. No personal-photo proposals are incorporated.
